# Green Framework 🌱

Green is a lightweight, modern PHP framework focused on **simplicity, speed, and developer experience**.

Green uses modern PHP features such as **PHP Attributes** to keep application code clean, explicit, and easy to understand.

## Green Ecosystem

The Green Framework is built from focused components:

### Core

The foundation of Green.

Contains the core framework functionality needed to build PHP applications, while keeping the architecture simple and explicit.

### Skeleton

The starting point for building Green applications.

Provides the application structure and the pieces needed to start a new Green project.

### Locale

Localization support for Green applications.

Provides the tools and resources needed to build multilingual applications.

## Philosophy

Green is built around a simple idea:

> Build what you need, keep it clear, and avoid unnecessary magic.

* Lightweight
* Modern PHP
* Explicit architecture
* Attribute-based routing
* Simple and predictable
* No unnecessary complexity
